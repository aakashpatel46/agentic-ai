# Foundations

This section builds the base mental model for agentic AI.

Before frameworks, tools, memory, or multi-agent systems, the goal is to understand what an agent is, what an LLM contributes, and why agent systems fail when their loops are poorly designed.

## Why This Section Matters

Agentic AI can sound complicated because people mix together models, prompts, tools, memory, orchestration, and automation. Foundations separate those pieces so later topics make sense.
