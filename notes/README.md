# Notes

This folder is the guided learning path for agentic AI.

The goal is not only to collect information. The goal is to build a public, readable trail from basic concepts to project-ready system thinking.

## Walkthrough

Start here:

1. `learning-map.md` - Big-picture map of the learning path.
2. `00-foundations` - Agent vocabulary, LLM basics, and the agent loop.
3. `01-agent-patterns` - ReAct, planning, routing, reflection, and structured outputs.
4. `02-tool-use` - Function calling, tool schemas, safety, and recovery.
5. `03-memory-and-rag` - Retrieval, embeddings, chunking, vector search, and memory.
6. `04-multi-agent-systems` - Specialist agents, handoffs, shared state, and review loops.
7. `05-evaluation-and-observability` - Tests, traces, security, cost, latency, and human review.
8. `project-readiness-checklist.md` - Checklist before starting a real project.

## How Each Section Works

Each section README is a mini learning guide with:

- A short purpose statement.
- A recommended reading order.
- A module map.
- Key questions to answer.
- A checkpoint before moving on.
- A link to the next section.

## Note Format

Each concept note should answer:

1. What is this concept?
2. Why does it matter for agentic AI?
3. How does it work?
4. What can go wrong?
5. What is a simple example?
6. What did I learn from it?

Use `_templates/concept-note-template.md` as the writing guide when starting or refining a note.

## Rule For This Repo

Do not rush into tools or frameworks before the mental model is solid. Frameworks change quickly. Concepts, tradeoffs, and failure modes last longer.
