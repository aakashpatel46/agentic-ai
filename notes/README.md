# Notes

This folder is the guided learning path for agentic AI.

The goal is not only to collect information. The goal is to build a public, readable trail from basic concepts to expert-level system thinking.

## Walkthrough

Read the folders in order:

| Step | Folder | What You Learn | Main Question |
|---|---|---|---|
| 0 | `00-foundations` | Agent vocabulary, LLM basics, and the agent loop. | What is an agent, really? |
| 1 | `01-agent-patterns` | ReAct, planning, routing, reflection, and workflows. | How do agents decide what to do next? |
| 2 | `02-tool-use` | Function calling, tool schemas, safety, and recovery. | How do agents act outside the model? |
| 3 | `03-memory-and-rag` | Retrieval, embeddings, chunking, and memory. | How do agents use external knowledge? |
| 4 | `04-multi-agent-systems` | Specialist agents, handoffs, reviewers, and coordination. | When should more than one agent be used? |
| 5 | `05-evaluation-and-observability` | Tests, traces, debugging, security, cost, and reliability. | How do we know an agent is working? |

## How Each Section Works

Each section README is a mini learning guide with:

- A short purpose statement.
- A recommended reading order.
- Notes to create.
- Key questions to answer.
- A checkpoint before moving on.
- A link to the next section.

## Note Format

Each concept note should answer:

1. What is this concept?
2. Why does it matter for agentic AI?
3. How does it work?
4. What can go wrong?
5. What is a simple example?
6. What did I learn from it?

Use `_templates/README.md` as the writing guide when starting a new note.
