# Concept Note Template

Use this template for concept notes.

```markdown
# Title

One or two sentences explaining the idea in plain language.

## Why It Matters

Explain why this concept matters for agentic AI systems.

## Mental Model

Give the simplest useful way to think about the concept.

## How It Works

Explain the mechanism step by step.

## Diagram

Add a Mermaid diagram when structure or flow matters.

## Simple Example

Show a small example in words, pseudocode, or code.

## Common Failure Modes

Explain what can go wrong and why.

## Design Tradeoffs

Explain when this idea is useful and when it adds complexity.

## Practical Takeaways

Summarize what to remember when building real agents.

## My Notes

Add personal reflections after reading, building, or testing.
```
