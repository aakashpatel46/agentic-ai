# Note Templates

This folder contains writing guides for future notes.

Use this template to keep the repo consistent and easy to read.

## Concept Note Template

```markdown
# Title

Short explanation of the concept in plain language.

## Why It Matters

Explain why this idea matters for agentic AI.

## Mental Model

Give the simplest useful way to think about it.

## How It Works

Explain the mechanism step by step.

## Simple Example

Show a small example in words, pseudocode, or code.

## Common Failure Modes

List what can go wrong and why.

## Practical Takeaways

Summarize what to remember when designing or evaluating agents.

## My Notes

Add personal reflections after reading, building, or testing.
```

## Style Guide

- Start simple, then add precision.
- Prefer concrete examples over abstract claims.
- Explain tradeoffs, not just definitions.
- Include failure modes early.
- Write like the reader is smart but new to the topic.
